## Trace a notification to its cause

@action: Open the bell or notification activity for Riverside Week thirty-eight and select one prepared assignment entry.

The activity view shows the path from rule match to contact, then member or external routing, channel, cadence, and any suppression or retry reason.

Use it when a recipient says they heard nothing. Check the event category, who caused it, project access, set mute state, recipient type, policy, and final delivery state instead of sending duplicate manual messages.

Bulk edits, re-publishes, and analysis runs are grouped. ClashWise does not send one email per clash, and your own actions do not notify you.

## Troubleshoot from the first possible stop

Start at the organisation. Is the notification master switch on, and is this category Member choice, Off by default, or Disabled for everyone?

Then inspect the set. A set-wide mute stops event recording and external access for that set. Next inspect the recipient's personal mute, category cadence, in-app toggle, operational-email state, and time zone.

For responsibility events, confirm the matrix contact's email and whether that person is an active member with project access. A member without project access can be routed externally; ClashWise never adds them to the project as a side effect.

Finally, use activity to read the recorded suppression or delivery reason. Change the responsible setting once, then create a new synthetic event. Muted history is not backfilled.

## Keep external outreach controlled

An external contact's read-only link shows only clashes assigned to them in the set. It does not expose the full project, 3D viewer, or member controls. Every live view is checked against current responsibility and set state.

Wise email adds a separate confirmation boundary. Review the draft, recipient, permanent clash numbers, and message before Send. The confirmed message uses a Wise action; drafting and cancelling do not send anything.

The successful result is not maximum notification volume. It is a traceable route where each audience receives the minimum useful signal at the rhythm they can act on.
