## Mute one set for yourself

@action: Use Wise or the profile controls to mute Archive Test Set, then show its chip in the muted-set list.

A personal mute silences every category for one clash set, for you only. It is useful for a test publish, an archived phase, or a set where you are only peripherally involved.

Remove the chip, or ask Wise to unmute the set, when you need the activity again. Notifications that occurred while muted are not backfilled.

## Distinguish a set-wide mute

The set owner or an organisation Admin can mute a set for everyone. In that state, events are not recorded, external emails stop, and secure external links for that set stop working while the mute remains.

Use that control for genuinely retired or noisy test sets. Do not use a global mute to solve one person's preference problem.
