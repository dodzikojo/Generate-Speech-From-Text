## Start the scheduled session

@action: Choose Start on the scheduled Riverside session and show the focus step for the larger set.

Start changes the session from Scheduled to Active. On a larger set, ClashWise first asks what you want to focus on so the meeting can open with a manageable slice.

Choose the prepared Level zero three review cohort rather than all forty to sixty training clashes. The session still belongs to Riverside Cycle zero one, but the initial room is focused on the agenda.

Only one session can be live on a clash set at a time. If ClashWise reports that another session may already be in progress, rejoin or end that session instead of creating competing records.

## Verify the live state before editing

@screen: Show the live banner on the set, the LIVE pill and timer in the viewer, and the live badge in the set list.

Before changing a clash, verify the session is visibly live. The set banner, viewer session bar, timer, and sidebar badge all confirm the active state.

That confirmation is the recording boundary. Changes made before Start or after End are normal clash history, but they are not automatic changes in this session.

The member profile now opens the same live room. Joined participants are added to the roster automatically, so the attendee record reflects who the room actually observed.
