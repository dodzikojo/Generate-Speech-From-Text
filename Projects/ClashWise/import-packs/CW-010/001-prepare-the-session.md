## Preview a meeting that records its work

@visual: Open the prepared active Riverside session with clash number twelve reviewed, one field change, one decision, one action item, and the attendee roster visible.

The value of a ClashWise session is not a video call or a blank minutes template. It is a live coordination state attached to a clash set.

While that state is active, changes to clash status, priority, responsible contact, and due date are recorded automatically with the clash, old value, new value, time, and person who made the change. Reviewed clashes, comments, captures, decisions, action items, attendees, and attachments build the wider record.

By the end of this lesson, Riverside Weekly Coordination will be active and will contain enough real activity to produce useful minutes in CW-011.

## Check the set and people first

@screen: Show Riverside Cycle 01 with the prepared review cohort, then the two clean browser profiles for owner and member.

Start from the clash set the meeting will review. Confirm it has the intended matrix, analysis state, and focused cohort. A session is scoped to one clash set, so choosing the wrong set creates the wrong record.

Use separate training browser profiles for the owner and member accounts. Close personal tabs, notifications, autofill, and unrelated organisations before recording. The synthetic attendees use example addresses and contain no customer data.
