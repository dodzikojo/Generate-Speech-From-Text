## Create Riverside Community Hub

@action: Open Projects, select New project, enter Riverside Community Hub and a short synthetic description, then create it.

Open Projects from the navigation. Each existing card shows the project name, your project role, its clash-set and member counts, and when it was last updated.

Select New project. Give the workspace a distinctive name: Riverside Community Hub, then create it. The current inline creation card asks for the name only.

The creator becomes the first project Owner. Project roles are Owner and Member. They are separate from organisation roles, which are Admin and Member. An organisation Admin is not automatically an Owner of every project.

Project creation depends on the current plan. Keep exact plan names and commercial allowances in the linked text reference, because those details can change faster than this workflow.

## Read the hub before filling it

@screen: Hold on the project header and the five tabs.

Clash sets lists the sets attached to this workspace. Tags aggregates the tag library across those sets. Matrices contains matrices shared into the project. Members controls project access. Settings lets an Owner rename, describe, or delete the workspace.

The empty Clash sets tab points back to the Clash sets page. Sets are attached from their own menu, not created inside this hub.

@action: Open Settings, add the prepared synthetic project description, and save changes.

The description is edited after creation from the Owner-only Settings tab. Use it to state the job or coordination scope, not to store secrets or a temporary meeting note.
