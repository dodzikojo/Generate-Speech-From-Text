## Move the first set into the project

@action: Open Clash sets, use the Riverside Week thirty-eight set menu, choose Move to project, and select Riverside Community Hub.

Return to Clash sets and open the More menu on Riverside Week thirty-eight. Choose Move to project and select the project.

The set now carries a project chip. Follow it back to the hub and confirm the set appears with its clash count, update time, and analysis state.

Repeat the action for the prepared Riverside Core set. A project can collect related sets, but each set can be attached to only one project.

## Move or remove without losing identity

@action: Open the first set menu again and briefly show Change project and Remove from project without confirming either.

After attachment, the same menu offers Change project or Remove from project. Changing the project moves the access boundary. Removing it returns the set to the personal model under its creator.

Neither action republishes the set. Clash number twelve remains clash number twelve in that set, and its coordination history stays with it.
