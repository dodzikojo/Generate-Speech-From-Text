## Give collaborators a predictable starting point

After invitation, send the project link and explain which set, matrix, and saved filter the person should open first. Project access solves visibility; it does not teach the project's coordination standard by itself.

Ask the member to apply the shared matrix to a prepared set only if they own or can manage that set. Sharing the matrix gives read and apply access, while the original matrix remains controlled by its creator.

Confirm that project tags appear consistently when the member opens the attached sets. If duplicate labels already exist, an Owner should agree and perform the project-wide rename before the library grows.
