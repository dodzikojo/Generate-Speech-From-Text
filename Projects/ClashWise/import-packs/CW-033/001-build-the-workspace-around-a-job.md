## Preview a useful project workspace

@visual: Open the prepared Riverside Community Hub project and move across Clash sets, Tags, Matrices, Members, and Settings.

A ClashWise project is an optional shared workspace around a coordination job. It does not detect clashes, create clash sets, or replace the person who owns them. Navisworks still detects the clashes, and the plugin still publishes each set.

What the project adds is a common home. The team can find related clash sets together, reuse a shared tag library, apply shared matrices, and return to saved filters created for the job.

In this finished Riverside workspace, two published sets, a coordination matrix, consistent tags, and the project team are visible without opening several personal accounts.

## Decide when a project helps

Use a project when more than one person coordinates the same job, or when one person needs a durable boundary between jobs. If you work alone and your sets do not need to be shared, leave them personal. Publishing, analysis, the viewer, and sessions still work.

A set can belong to only one project at a time. Attaching it does not change its permanent clash numbers, history, or creator. It changes who can reach it through the project.
