## Add the Riverside coordination matrix

@action: Open the Matrices tab, select Add matrix, choose the prepared Riverside Coordination matrix, and confirm.

Select Add matrix. The dialog lists matrices you created, because a matrix remains owned by its creator even when it is shared.

Choose Riverside Coordination and add it. Project members receive read access so they can inspect and apply the standard to their own sets. They cannot silently edit or delete somebody else's matrix.

If a matrix is marked In another project, sharing it here moves that project association. Pause and confirm that is intentional.

The creator can later remove the matrix from this project. Removal ends the shared access but does not delete the original matrix.

## Connect projects, sets, and matrices correctly

Putting a set and a matrix in the same project does not assign that matrix automatically. Open the relevant clash set and apply the shared matrix through the normal matrix assignment workflow.

Projects provide visibility and reuse. The set still records which matrix is actually assigned, and analysis still works from the applied rules.
