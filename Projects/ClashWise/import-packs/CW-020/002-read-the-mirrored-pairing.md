## Understand the cross-tab

@screen: Highlight the upper triangle, diagonal, inert lower mirror, priority legend, and optional status dot.

The interactive rules occupy the upper triangle and diagonal. The lower triangle is an inert mirror, not a second directional rule.

So Ducts versus Beams and Beams versus Ducts refer to the same class pairing in this view. The earlier curriculum note suggesting two independent directions does not match the shipped matrix.

Each cell summarises the rules inside that discipline or category pair. The displayed number is the worst configured priority order, and the optional dot shows the dominant status. Hover for counts and missing-contact information.

## Open the pair popover

@action: Open the Ducts versus Structural Beams cell and show Contact, Priority, Status, overwrite switches, and View rules.

Each value has its own Apply action. With Overwrite existing assignments on, the selected value replaces existing values across every rule in the cell. With it off, ClashWise fills only rules that are empty.

Before a cell-wide edit, use View rules to confirm how many underlying class rules the summary represents.
