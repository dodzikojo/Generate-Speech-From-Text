## Manage the available priority and status values

@action: Open More, Manage priorities, inspect the prepared High option and its colour, then Manage statuses and inspect Active.

Priorities and statuses are project-defined names with configured colours. ClashWise does not impose one universal engineering scale.

Create or edit values in the matrix's option libraries. A value already used by rules cannot be deleted; deactivate it or reassign those rules first. Default options can be deactivated but not removed.

The configured hex colour is authoritative. Change it here and the cross-tab, clash grid, and Excel output follow the same value.

## Confirm the contact and tag libraries

@screen: Open Manage contacts and Manage tags, then return to the target rule.

Contacts belong to the matrix and include name, company, and email. Updating a contact across the library changes every rule that uses that contact. Deleting it removes the assignment from those rules.

Tags flow from matched rules onto clashes during analysis only when Generate and assign tags is enabled. The library also supplies autocomplete suggestions for manual clash tagging.

Check the NO CONTACT warning before analysis; a rule cannot recommend responsibility without a contact.
