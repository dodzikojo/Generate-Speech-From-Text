## Publish a clash set

@action: Select a prepared clash test in Navisworks and open the Publish workflow.

The cycle begins after you have run your clash tests in Navisworks.

Choose Publish, select the tests you want to coordinate, give the set a useful name, and send the results to ClashWise. The plugin can include viewpoint images, three-dimensional captures, model context, locations, and element properties alongside the clash data.

When processing finishes, the set appears under Clash sets on the web. Every clash receives a permanent number within that set. Lead with that number in meetings, links, comments, and reports, because the number stays stable even when a title changes or the set is updated.

## Apply your coordination rules

@screen: A prepared Clash Matrix followed by the matrix selector and Run analysis action on the clash set.

A published set starts as clash information from Navisworks. To turn it into a coordinated worklist, create and assign a Clash Matrix.

The matrix is your project rulebook. Each element-class pairing can carry the priority, status, responsible contact, tolerance, and tags your team wants to use. ClashWise does not impose a fixed engineering taxonomy. Your matrix defines what the recommendations mean for this project.

When you run analysis, ClashWise matches each clash to the most appropriate matrix rule and adds a recommended priority, status, and responsible contact. The matched rule remains visible, so you can see where the recommendation came from.

These recommendations accelerate review; they do not replace coordination judgement. The team can accept them, change them, or record an intentional exception.

## Triage with the right context

@visual: Move from the clash grid to one clash detail view, then briefly show its three-dimensional model view.

The clash grid is the main work surface. Search, filter, group, sort, and select clashes to focus the review. Use tags, due dates, assignments, and safe bulk actions to turn a long result list into packages of work.

Open a clash to bring its permanent number, viewpoint, model properties, location, analysis, recommendations, comments, and history together. When geometry needs more context, move into the browser-based three-dimensional viewer and isolate the issue without passing control around a Navisworks workstation.

The important change is not simply that the clash is online. The source result, the recommendation, and the team's decision can now be understood separately and traced later.
