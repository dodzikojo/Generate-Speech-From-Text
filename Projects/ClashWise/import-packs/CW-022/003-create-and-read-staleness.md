## Change the underlying rule

@action: Edit the prepared rule used by another unlocked clash, then return to the grid without rerunning analysis.

The matrix now contains a newer value, but the clash still displays the recommendation saved by its earlier analysis.

The stale marker warns that the recommendation may no longer reflect the current rule. ClashWise does not silently rewrite analysed clashes when the matrix changes because that would erase the moment at which the recommendation was produced.

## Decide whether to rerun

@screen: Compare the stale unlocked clash with locked override number eighteen.

Rerunning analysis refreshes unlocked clashes against the current matrix. Locked manual overrides remain protected, even if their linked rule also became stale.

Unlock only when the coordinator wants analysis to own the values again. Stale and locked are independent facts.
