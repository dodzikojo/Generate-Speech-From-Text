## Group and filter inside the scene

@screen: Group the loaded list by Level or Priority and apply a minimum-penetration filter.

Viewer grouping and facets operate only on the loaded scope. They do not bring excluded grid clashes into the scene.

Use Sort worst first and minimum penetration to focus a geometry review, but keep the original scope chip visible so the meeting knows what is not loaded.

## Choose the scene mode for the question

A focused clash scene is best for detailed geometry around a small cohort. A broader context model helps the team understand location and routing, but can reduce performance and make the collision harder to read.

Use colour by priority or another coordination value when comparing risk across several clashes. Use element or discipline colours when the question is which systems are involved. Reset appearance before switching questions so old colours do not imply current meaning.

Isolation removes visual noise; focus keeps muted context. State which mode is active before discussing what is absent from the screen.
