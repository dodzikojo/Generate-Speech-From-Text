## Add without touching existing rules

@action: From the matrix More menu, choose Add classes from clash set and select Fire Damper and Transfer Beam.

Add classes pairs each new class against the existing class list and against the other new classes. Existing rules are not changed.

Review the projected rule count, disciplines, and extraction preview. Select only the two valid new classes and start the background operation.

When it completes, open the old custom Ducts versus Beams rule. Its priority, status, contact, tags, and tolerance should be unchanged.

## Configure the newly created rules

@screen: Filter the table to rules containing Fire Damper or Transfer Beam and show missing fields.

New rules begin from the current generation and evaluation process. Review them as new project decisions.

Use the filtered rule count, fill contacts deliberately, inspect priority and status, and keep the NO CONTACT warning visible until coverage is complete.
