## Understand exact synchronisation

@action: In the prepared safe matrix copy, choose Sync with clash set and review classes to add and remove.

Sync reconciles the matrix to the current class list. It adds missing classes and removes rules for classes that no longer exist in the source set.

Surviving rules preserve user-edited priority, status, contact, and tags. Removed classes take every rule that references them, so review the removal list before confirming.

Use this after a significant model update, not as a reflex after every small republish.

## Compare Sync with Remove classes

@screen: Show More, Remove classes on the safe copy and its irreversible warning without confirming another removal.

Remove classes is the manual pruning route. Selecting one class removes all of its rules and cannot be undone through the web control.

Sync derives the exact list from a clash set. Manual removal expresses a matrix-owner decision independent of one set. Both deserve a before-state export or documented comparison.
