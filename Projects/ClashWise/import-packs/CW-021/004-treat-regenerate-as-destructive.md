## Read the Regenerate warning

@action: Open Regenerate from clash set or sets on the prepared copy and pause at the warning.

Regenerate rebuilds the rule list from scratch. It preserves the matrix name, available priority and status options, and contact library, but it discards per-rule tolerances, priorities, statuses, and contacts.

The earlier run sheet suggested regeneration would preserve unrelated intentional rule values. The shipped workflow explicitly warns that it will not.

Use multiple source sets when the fresh matrix genuinely needs their combined classes. Export or otherwise document the old rule assignments before confirming.

## Re-evaluate without rebuilding classes

@screen: Cancel Regenerate, choose Re-evaluate on the rules toolbar, and show the prepared progress state.

Re-evaluate asks AI to rescore rule priorities and statuses without changing the class list. Editing is locked while it runs, and Stop is available.

Completion reports how many priorities and statuses changed. Contacts, tags, tolerances, and intentional manual decisions still need human review; re-evaluation is not a company-standard approval step.
