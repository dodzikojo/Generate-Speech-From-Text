## Preview a verified Wise result

@visual: Show clash number twelve in a Wise card, then the matching web record with its prepared owner, due date, and comment.

Wise is the AI assistant built into ClashWise. In Navisworks it can answer questions about published clash sets, return interactive clash cards, update coordination fields, and control the model view.

It does not detect clashes. Navisworks Clash Detective does that. Wise works with the results you have published and with the live Navisworks context you deliberately share.

The safe pattern is simple: set a narrow scope, ask for a small outcome, inspect what Wise says it did, and verify the record in its native surface.

## Open the full chat surface

@action: On the ClashWiseAI ribbon, select Chat and show the welcome card.

Wise chat requires a signed-in Clash Management account and the Full Suite plugin. The Chat button toggles the dockable pane, which can be resized or moved like other Navisworks windows.

Choose a prepared published clash set from the focus card. A scope chip confirms whether the conversation sees all clash sets or one selected set.
