## Find the wider coordination workspace

@action: Move through Dashboard, Projects, Coordination setups, Clash matrices, Shared insights, Organisation, and Profile in the navigation drawer.

Dashboard is the coordination console: recent sets, live sessions, analysis activity, and shortcuts into current work.

Projects are optional team workspaces. They bring selected clash sets, matrices, tags, saved filters, members, and settings together without changing how private sets work.

Coordination setups connect a federated model, its source and class mapping, a default matrix, and the managed search sets and tests installed back into Navisworks. Open the setup to check scan freshness, matrix coverage, and installation status.

Clash matrices holds the coordination rulebooks used by analysis. Shared insights is the control centre for external dashboard and scene links, including copying, extending, and revoking access.

Organisation is where owners and admins manage the plan, seats, members, roles, billing, and session defaults. Profile contains personal details, time zone, display units, notification preferences, usage information, and developer API access.

The sessions hub gathers scheduled, live, and ended sessions across clash sets. Depending on the current navigation, you may reach it from a set's Coordination action or directly from its page.

Models and three-dimensional scenes are normally reached from the clash set you are reviewing. Insights is also set-specific: it turns coordination data into a dashboard that can be arranged for a meeting or shared through a controlled link. Integrations and developer access are kept with the account and organisation tools because they can expose data beyond a single browser session.

## Use the next-action guidance

@screen: Show the dashboard getting-started guide and the selected clash set's next-action progress pill.

New workspaces include guidance so you do not have to remember the sequence. The model-first path leads from Coordination setup and matrix review through native tests, publishing, analysis, coordination, and sync. The publish-first matrix-from-set path remains available for a dedicated rulebook. On an individual clash set, the progress pill highlights the next available action and warns when a set changed after analysis.

Live badges and banners also matter. They show when analysis is running, a session is active, an export is being prepared, or an organisation is read-only. Treat those states as part of the workflow, not decoration.

If an organisation is read-only, you can still inspect existing work and export where permitted, but editing actions are disabled. If you switch organisations, the page reloads and the data is re-scoped. Pause after any switch and verify the organisation name before inviting people, publishing, or creating shared links.

One final orientation tip: use links from the current object whenever possible. Open the matrix from the set that uses it, the session from its Coordination panel, and a clash from its permanent-number link. That preserves context and reduces hunting through global lists.

You now know where a task begins: model-dependent preparation in the plugin, shared coordination on the web, and account or team settings under Profile and Organisation.
