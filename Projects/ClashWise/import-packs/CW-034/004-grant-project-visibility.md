## Add the new member to Riverside

@action: Open Riverside Community Hub, invite the same synthetic account as Project Member, then switch to its prepared profile.

Organisation membership does not automatically reveal every project. Open Riverside Community Hub and add the person to that project's Members tab.

Now verify from their profile. They can see Riverside and its attached sets, shared tags, matrices, and saved filters. They cannot see another project or personal set unless they have separately been given access.

This is the practical boundary to test whenever a user says a set is missing: confirm the active organisation, then confirm the project membership.

## Avoid accidental privilege coupling

Changing somebody to organisation Admin does not make them a project Owner. Changing them to project Owner does not grant billing access. Make each role change in the surface that owns it.
