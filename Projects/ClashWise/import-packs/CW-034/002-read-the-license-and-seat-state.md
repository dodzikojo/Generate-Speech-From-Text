## Inspect license and seats

@action: Open Organization and hold on tier, status, seats used, seats purchased, and renewal or trial date.

The organisation header identifies the active organisation, current tier, and status. The License and seats area shows consumption against purchased seats.

An active member consumes a seat. A pending invitation also reserves one until it is accepted or expires. If no seat is available, remove an obsolete member or invitation, or adjust the seat count before inviting again.

Only an Admin can change seats or open billing. Do not quote prices or exact plan allowances in this recording. Link to the live pricing and billing reference, where those values can stay current.

## Recognise read-only mode

When a trial ends without an upgrade, or the organisation subscription is inactive, the cloud workspace becomes read-only. Existing data remains viewable and exportable, but writes, member changes, and license changes are blocked.

Read-only is an entitlement state, not a data-deletion warning. An Admin can restore normal access through the current upgrade path.
