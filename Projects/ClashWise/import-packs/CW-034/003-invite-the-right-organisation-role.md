## Invite a Member

@action: In Members, enter coordinator dot two at northstar dot example, choose Member, and select Invite.

Use a synthetic address for this demonstration. Choose Member for a coordinator who needs product access but should not control the organisation.

An existing ClashWise account receives access immediately. A new address appears as Pending and must sign in using that same address. Pending invitations expire according to the current policy and release their reserved seat.

The roster shows Active or Pending alongside each role. This is where to diagnose an invitation that was sent to the wrong spelling or has not yet been claimed.

## Use Admin sparingly

Admin can invite and remove members, change roles, rename the organisation, adjust seats, manage billing, and change team-wide controls. Promote a Member only when those responsibilities are part of their job.

The final Admin cannot be removed or demoted. Promote a replacement first so the organisation is never left without an administrator.
