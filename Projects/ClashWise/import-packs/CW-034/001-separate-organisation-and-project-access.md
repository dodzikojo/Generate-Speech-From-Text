## Preview the finished access model

@visual: Show the Northstar organisation roster, then the Riverside project roster from the prepared second profile.

ClashWise has two different access layers.

The organisation holds the subscription, seats, billing, team-wide defaults, and the Admin or Member role. A project groups specific coordination work and has its own Owner or Member role.

The same person can be an organisation Member and a Riverside project Owner. Or they can be an organisation Admin without belonging to a particular project. Keeping those layers separate avoids granting broad commercial control just because somebody coordinates one job.

## Start from the least access required

Before inviting anyone, decide what they need to do. Organisation Admin is for people who manage membership, seats, settings, and billing. Organisation Member is the normal product role.

Then add that member only to the projects they need. Project Owner is for project membership, settings, and tag governance. Project Member is for working with shared coordination content.
