## Rename one title in context

@action: Use the pencil on a prepared title, enter the clearer synthetic title, and press Enter.

The current grid supports manual and Wise-assisted title renaming. A manual editor saves on Enter and cancels on Escape or blur. The row changes optimistically, then reconciles with the server response; a failure restores the prior title. A web-edited title is marked as edited and survives a later Update.

The title still does not sync back to Navisworks. Keep the permanent clash number as the handoff identity.
