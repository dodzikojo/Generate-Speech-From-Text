## Group and sort within the cohort

@action: Group by Status then Level, and sort the result by Due Date.

Grouping reveals sub-packages; sorting orders the work within them. Review status remains its own progress signal and does not become a lifecycle status merely because it is grouped nearby.

Group headers show counts and provide a direct 3D route for that group.

## Save the filter as a live view

@action: Save as “L02 High Unassigned,” reopen it from the sidebar, then clear the view state and return.

A saved filtered view stores the definition, not copied clashes. Edits made through the view affect the parent records, and the view's membership changes as values change.

Clear the active filter to return to the full set without losing those edits. Delete a saved view only when the reusable definition is no longer needed.
