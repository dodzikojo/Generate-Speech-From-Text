## Select the set and scope

@action: Choose Clash Management, Sync, select Riverside Cycle 01, and open the Clash Set Summary.

The Sync window lists accessible clash sets. Confirm the set name, clash count, included test names, project, and last update before selecting it.

In the summary, choose Analyzed clashes only for the normal matrix-driven path, or All clashes including manually edited when web edits outside analysis must also be included. Use tag filters when only one work package should return to the model.

Review the analysis statistics, priority and status distributions, top contacts, and matched rules. If the summary looks wrong, correct the web data before writing anything into Navisworks.

## Choose only the fields you need

@screen: Show the priority, status, contact, comment, and group settings in the sync configuration.

Enable the supported fields required for this cycle. Map ClashWise priorities to the native High, Medium, or Low values, and map ClashWise statuses to the available Navisworks statuses.

For responsible contact, choose whether Navisworks receives the contact name, email, or company. Edit the sync comment so a later reviewer understands when and why the fields were written.

If web-created groups are waiting, review which groups will be created or removed in each clash test. Untick any group operation that does not belong in this model cycle.
