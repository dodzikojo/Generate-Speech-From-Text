## Understand what refreshes

@screen: Show the update checklist, then the processed set with its new and existing clashes.

Update refreshes clash data, levels, grids, element-property indexing, and chosen context. New tests receive new viewpoint captures; existing captures may remain unless the current update workflow explicitly replaces them.

The set reports that its data changed after the previous analysis. That warning is the cue to review matrix coverage and rerun analysis for new or changed clashes.
