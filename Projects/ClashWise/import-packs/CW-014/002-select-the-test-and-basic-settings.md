## Open Title Update and choose one test

@action: From General, choose Title Update, search for the prepared test, and tick only that row.

The Clash Tests tab lists test name, type, issue count, and grouping information. Select the small prepared test only. A grouped test can contain both group and individual results, which the later scope controls handle separately.

The amber reminder about Property Mapping is not a second mapping editor. Use the footer button to review the dedicated Property Mapping window when needed.

Start becomes available after at least one test is selected, but mapping and saved-document checks still run when you click it.

## Use a conservative first-run configuration

@screen: Open Settings, choose Basic, English, Title, New clashes only, Individual clashes only, and Review before applying.

For this lesson, choose the Basic naming standard, English, and Title as the destination. Keep New clashes only selected and apply to individual clashes only.

Keep Review titles before applying turned on. This is the safety boundary: generation stages proposals in a review window and writes nothing until you choose Apply.

Confirm the active model named in the AI Model panel. Naming uses that local model. Cloud AI is not a second primary mode in this window; it is an optional fallback used only after a local failure when the account permits it. Leave fallback off for this demonstration.
