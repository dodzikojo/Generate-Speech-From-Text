## Open the right self-service route

@action: Choose Dashboard, then Help, and show the plugin version without exposing the user's browser profile.

Dashboard opens the signed-in web workspace. Help opens the public searchable help centre. Use the help route for exact error messages, version tables, storage paths, and recovery steps that change faster than a video.

Record the plugin version shown by the current interface as part of any issue report. Navisworks year, plugin version, model state, and the exact action are more useful than saying the latest version.

## Understand update behaviour

@screen: Show prepared optional-update and required-update states.

An optional update can be deferred until a convenient restart. A required update prevents incompatible continued use and routes to the download page.

Close Navisworks before installing the new version. Reopen the same safe training document and reproduce the problem once after updating before escalating.

If the ribbon does not load at all, verify installer edition and Navisworks year as shown in CW-002.
