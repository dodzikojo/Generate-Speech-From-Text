## Write a reproducible summary

@action: Choose Report Bug and enter the synthetic title and numbered reproduction steps.

Report Bug opens a direct support form and automatically includes plugin logs. Use the title Title Update review rows stop after retry.

In the description, include the Navisworks year, plugin version, safe document state, selected test, exact steps, visible message, expected continuation, and actual stopped state.

If you are signed out, provide an email address support can use. A signed-in report already has account context.

## Choose attachments deliberately

@screen: Add a synthetic screenshot, show the size limits, and leave the model file unattached.

Attach the cropped synthetic screenshot. Do not attach a model, export, or configuration merely because the form permits it.

Review every chosen file for customer names, personal email, API tokens, storage URLs, and unrelated paths. The current form enforces per-file and total size limits; keep exact numbers in the linked support article.

Logs are attached automatically. They can contain technical paths and service detail, so use the built-in report route and the product's support handling rather than posting logs publicly.

## Write a reproducible report

A useful report describes the starting document, plugin and Navisworks versions, exact command, selected tests or clashes, expected result, actual result, and whether the problem repeats after reopening the tool.

Replace statements such as it does not work with an observable result: after selecting Publish, the job remained Queued for ten minutes and no set appeared on the web. Include the local time and synthetic set name so support can correlate service activity.

Attach the smallest safe screenshot or file that proves the issue. More data is not automatically better evidence.

## Choose recovery before escalation

For a hidden or confusing model state, first use the plugin's visibility controls: show the selected clash, reset hidden items, restore appearance, or reopen the saved viewpoint. For a stale web state, refresh the relevant card or reopen the set before repeating a write.

Use Dashboard and Help to confirm connectivity and current guidance. Check the displayed plugin version and update state. Restart Navisworks only after saving unrelated work.

If recovery succeeds, still report a repeatable defect when it can cause lost time or unclear state. The goal of the bug report is not merely to unblock this session; it is to give support enough evidence to reproduce and fix the underlying path.
