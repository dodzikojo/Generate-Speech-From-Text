## Keep three capture concepts separate

Snapshot exports the current ordinary viewer image as a P N G or copies it to the clipboard. It is a point-in-time picture and does not create a collaboration link.

Session Capture belongs to an active coordination session. It records an image in the meeting context, where markup and the session record can preserve what the team discussed.

Share scene creates a protected web experience from the selected 3D scope. It preserves interactive viewing according to the share's current permissions and limits. Do not narrate these three controls as versions of the same action.

## Build a useful shared scene

Before sharing, reduce the scene to the question the recipient must review. Keep enough context to identify location, but remove unrelated clashes and models. The current sharing limit is one hundred and fifty clashes, so use a focused cohort rather than an entire large set.

Open the generated link in a signed-out browser. Enter the password, verify the intended clashes and controls, and confirm no authenticated-only Wise or project navigation appears.

Finally, revoke the link and reload the recipient page. A share is not closed until the old URL no longer grants access.
