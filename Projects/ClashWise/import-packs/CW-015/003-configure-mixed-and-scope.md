## Limit what Mixed may choose

@action: Select Mixed, open Mixed configuration, and tick only the project-approved built-in and custom formats.

Mixed can alternate among built-in and custom standards. The configuration checklist limits its choices. If nothing is selected, all available standards are eligible.

Use Mixed when variation is acceptable and the model should choose the clearest approved structure per clash. Avoid it when a contractual naming standard requires the exact same pattern every time; use a token format instead.

## Control which results are processed

@screen: Review New clashes only, Review before applying, Apply To, and Include Previously Updated Clashes.

New clashes only is the conservative default. Include Previously Updated Clashes is useful after changing the project standard or output language.

Apply To can target individual clashes, individual clashes and group titles, or group titles only. Groups have no description field, so a Description destination skips group rows.

Keep Review before applying enabled for the first full project run. Automatic apply is useful only after the team trusts the configuration and recovery process.
