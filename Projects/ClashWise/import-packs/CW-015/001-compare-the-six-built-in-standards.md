## Show one clash six ways

@visual: Display the same prepared clash through Basic, Detailed Descriptive, Component ID Information, By Discipline, AI Preferred, and Mixed previews.

A naming standard decides what the title helps the reader recognise first.

Basic emphasises the two readable element names. Detailed Descriptive adds types, categories, and locations. Component ID Information favours traceable types and source identifiers. By Discipline adds trade context. AI Preferred lets the local model decide which information is most useful for the clash. Mixed lets the model choose among the standards you permit.

The best choice is the convention your project will use consistently, not the longest available sentence.

## Choose human meaning or stable traceability

@screen: Compare a readable equipment name with an element ID that remains stable across coordination references.

Readable names help people scan a meeting list. Stable IDs help trace a precise element when several objects share a similar name.

Use Component ID Information when element identity matters more than conversational phrasing. Use Basic or a human-readable custom format for rapid coordination. A detailed title can be valuable in reports but unwieldy in a narrow Clash Detective tree.

Pick one default for the project and use exceptions deliberately.
