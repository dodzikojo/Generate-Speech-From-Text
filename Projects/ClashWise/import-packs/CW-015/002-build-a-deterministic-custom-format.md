## Open Manage formats

@action: Choose Manage formats, create “Northstar level and elements,” and add a description.

Custom formats support a controlled project convention. Give the format a name people will recognise in the dropdown and a short description of when to use it.

Token formats are deterministic. ClashWise fills the selected values exactly where the tokens appear; it does not ask AI to rewrite that string.

Freeform custom instructions without tokens still use the model, and group titles are also worded through the model.

## Create the sample token pattern

@action: Insert the current Level and element-name tokens to produce “level, hyphen, item one, versus, item two,” then inspect the live preview.

Use the chips shown by the shipped editor. The current token names include Name one, Name two, element type or category, level or layer, element ID, and discipline for each side.

Build the equivalent of Level, hyphen, Item one Name, versus, Item two Name using the actual square-bracket token syntax presented in the editor.

The original plan used brace-style placeholders, but the shipped plugin uses square-bracket tokens. Copy the tokens from the UI rather than typing a remembered syntax.

If a selected clash has no Level value, the preview exposes that gap. Return to Property Mapping when the value should exist; do not disguise a systemic blank with punctuation.
