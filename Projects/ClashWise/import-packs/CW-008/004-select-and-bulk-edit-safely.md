## Read the selection scope before acting

@action: Select three visible training rows and open the bulk bar; point to the exact selected count.

Select only the three prepared clashes. The bulk bar reports the current scope. A filtered grid may also offer Select all matching, which can extend beyond the current page, so read the wording carefully.

Do not carry a hidden selection from an earlier filter into a new bulk action. If the number is unexpected, choose Clear selection and rebuild it.

For a first demonstration, use a responsible contact or due date rather than bulk close. The result is obvious, useful, and easy to correct.

## Apply and verify a reversible change

@action: Assign the prepared MEP lead to the three selected clashes, confirm, then clear the selection and filter to that contact.

Assign the M E P lead and confirm the action. The visible rows update immediately while ClashWise persists the change and reconciles the canonical response. A failed write rolls the affected row back and reports the problem instead of leaving a false success on screen.

Now clear the selection and filter by that contact. Exactly the three intended clashes should appear. Open one row to confirm the value, then return to the grid.

Apply defaults is another bulk action. It stamps matrix default priority, status, and contact onto the selected cohort. Use it only after reviewing the matrix and scope; it is not a substitute for triage.
