## Preview the triage result

@visual: Show a filtered Riverside cohort grouped by level, sorted by due date, with two reviewed rows and three selected clashes assigned to the prepared contact.

Triage is not scrolling until something looks important. It is reducing the set to a defined cohort, checking the scope, and applying only the changes that the evidence supports.

In this lesson, we will find a clash by permanent number, search by content, combine filters, group and sort the result, mark review progress, and make one reversible bulk assignment.

The selection count is our safety check. Before any bulk action, it must agree with the clashes visible in the intended cohort.

## Search by identity and language

@action: Clear the prepared state, enter number twelve, open the row, then search for a title or property term.

Start with clash number twelve. The permanent number is the fastest way to find the exact issue discussed in a meeting or link.

Now search for a plain title or property term such as air handling unit. Universal search scans the indexed clash data as you type and supports AND, OR, NOT, wildcards, and quoted phrases. Use those operators when a single term is too broad, but keep the query readable enough to explain to another coordinator.

Search narrows what you see; it does not select or edit those rows.
