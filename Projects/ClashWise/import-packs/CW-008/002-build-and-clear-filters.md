## Use quick filters for common coordination fields

@action: Filter in turn by recommended priority, recommended status, responsible contact, tag, and reviewed state, clearing each before the next.

Apply one filter at a time first so its effect is visible. Filter to the prepared High priority, then to the intended status, contact, project tag, and Not reviewed state.

Recommended priority and status are available because Riverside has an assigned matrix. A set without a matrix cannot filter fields that do not yet exist.

Watch the active filter summary and result count. Clear each filter deliberately before adding the next, then combine only the conditions required for the real work package.

## Build a precise condition set

@screen: Open Filter clashes, show the plain-language mode and the manual AND or OR builder, then apply the prepared Level 03 cohort.

The filter dialog offers two routes. Describe the intended slice in plain language and let the smart filter translate it, or build conditions by hand with nested AND and OR groups.

The manual builder can use clash fields, key element properties with an A, B, or Either side, the full published property index, dates, and spatial relationships. For this activation lesson, keep it simple: Level zero three, not reviewed, and the prepared responsibility state.

Apply the filter and read the summary chips back. If the result is empty, remove conditions one at a time rather than changing several guesses together.
