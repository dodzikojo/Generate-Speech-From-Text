## Understand profile default precedence

@screen: Compare a Profile Default set with a prepared Explicit set assignment.

Riverside Cycle zero one uses Profile Default. If the setup's default matrix changes, a new set uses it immediately and this existing set adopts it on the next republish.

An Explicit assignment always wins. A matrix deliberately attached to a set, including a dedicated matrix generated from that set, keeps its own matrix and extraction mapping on republish.

That distinction supports both workflows. The profile supplies a durable federation standard. A particular clash set can still branch into a dedicated rulebook when the package genuinely needs different coordination intent.

Creating a matrix from an already published set remains available and is covered in CW-zero-two-one. It is now the dedicated or recovery path, not the prerequisite for every first publish.

## Reconcile before every native write

@visual: Change one rule tolerance, show its safe Update row, then show a manually changed managed test preserved as Conflict.

When the matrix changes, return to the setup, refresh the reviewed matrix, and read the diff before applying anything. A clean managed artifact can update. A native edit remains a conflict until a person resolves it.

That rule is the safety contract: ClashWise automates repetitive definitions without taking ownership of unrelated work or silently overwriting a coordinator's changes.
