## Explode a useful property into candidates

@action: Open Presets by value, load the prepared system property, and review the distinct values.

Presets by value creates one local recipe per selected property value. Load values from the model, then choose only the systems that support the project's clash-testing standard.

Use exact matching for controlled values and contains only when the stored convention genuinely requires partial matching. A name prefix such as M E P keeps the preset library readable.

The value list can be large and is capped in the shipped tool. Do not turn thousands of noisy values into thousands of presets.

## Combine and materialise selected presets

@screen: Combine the system values with the current MEP scope, preview example names, create presets, then create native sets from the selected recipes.

Combine with current conditions intersects each value with the scope already built in the window. This prevents a shared property name in another model from broadening the set.

Create the useful presets, review one definition, then select the intended recipes and choose Create sets. Presets live on this Windows profile; search sets live in the Navisworks file.

Export a preset bundle when the team needs the same definitions on another workstation.
