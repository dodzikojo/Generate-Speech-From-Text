## Preview the native outcome

@visual: Show MEP Supply Air and STR Beams in the Navisworks Sets window, then the MEP Ducts versus Structural Beams test in Clash Detective.

Sets and Clashes builds native Navisworks search sets and clash-test definitions. It is not the web Clash Matrix.

Search sets define which model elements belong in a selection. Clash tests pair those selections so Navisworks can detect results. The web matrix can now sit before detection: a Coordination setup turns each eligible active matrix rule into one managed test. It is also used after publishing to recommend coordination values.

ClashWise creates the test definition here, but Navisworks still runs clash detection. This lesson covers the manual builder for bespoke sets and tests. CW-zero-zero-six covers managed creation from a reviewed matrix.

## Open the visual builder

@action: Choose General, Sets and Clashes, and show the builder beside the Navisworks model.

The window stays alongside Navisworks so match counts and model selection can be checked live. Presets on the left are reusable local recipes. The builder on the right creates or edits one definition.

Use Whole model when every appended source belongs in scope. Use Current selection when the search must stay inside a deliberate building, zone, or model branch.
