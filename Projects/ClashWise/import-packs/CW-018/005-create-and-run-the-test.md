## Create one linked clash test

@action: Choose Create clash test from sets, select MEP Supply Air and STR Beams, and enter the prepared test name.

Choose the two different native search sets as Selection A and Selection B. Name the test M E P Ducts versus Structural Beams.

Select Hard or Clearance according to the project requirement and set the tolerance in metres shown by the dialog. Read the numeric unit carefully; it may differ from the display convention elsewhere in the project.

Choose Create. The native Clash Detective test is linked to the search sets, so future set-condition changes flow into its selections.

## Run and verify in Clash Detective

@action: Open the created test, show its linked selections, run it in Navisworks, and inspect the result population.

The confirmation says the test was created, not performed. Open Clash Detective and run it yourself. ClashWise never runs detection.

Compare the result population with the expected Riverside sample. If it is unexpectedly large, return to the search-set match and overlap checks before publishing anything.

The batch creation option can pair several sets against each other and optionally create self-intersection tests. Use its projected count and name-collision policy to review the scope before creating a battery of tests.

Manual tests remain outside a Coordination setup's managed manifest unless they were created by that materialisation. The installer will not rename, update, or remove them. They can still be published from the same remembered federation and inherit its profile-default matrix when the binding validates.
