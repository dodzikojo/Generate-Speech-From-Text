## Compare current and recommended values

@screen: Place the Navisworks-sourced Status and Priority beside the ClashWise recommendation columns for clash number twelve.

Published clash information describes the state that came from Navisworks. Recommendation columns describe what the current matrix analysis proposes.

A recommendation is advisory until someone applies or saves a coordination value. Seeing High in a recommendation column does not mean the team has agreed that clash number twelve is High, and it does not alter the Navisworks document by itself.

The separation lets the coordinator challenge the recommendation without losing source context. Review the clash, accept the proposed value when it fits, or choose an intentional override when project knowledge says otherwise.
