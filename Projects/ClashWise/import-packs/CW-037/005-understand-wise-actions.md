## Separate browsing from AI requests

Every message sent to Wise that completes AI work uses one Wise action, whether it answers a question or applies several scene commands. A failed request is not charged.

Orbiting, selecting, opening the inspector, changing a field manually, and ordinary viewer browsing do not consume Wise actions. In Navisworks, editing the chips on already-returned cards is also ordinary product activity.

Batch related instructions when the combined result is safe to review. Split unrelated or high-impact work into separate requests so the outcome remains obvious.

@action: Open the Profile AI usage area in a prepared tab and show the current meter without quoting an allowance.

Allowances vary by current plan and period. Use the meter and live pricing reference instead of a number recorded in the narration.

## Use the scene as the conversation contract

Before each message, read the scope chip, visible clash count, active filter, isolation state, and current selection. Wise interprets the scene at send time. A filter you changed after the last reply can change what words such as these or worst refer to.

Prefer a sequence the viewer can verify: show only the target cohort, focus one permanent clash number, change a presentation mode, then explain the selected clash. Confirm each action chip before the next request.

If an action is skipped, read the reason. A clash outside the loaded scene requires a different scope. An unavailable view mode requires a supported command. Retry only after changing the cause.

## Choose between Wise and manual controls

Use Wise when natural language combines several viewer steps or when you need an explanation. Use the clash list, inspector, and toolbar when the target and control are already visible. Manual browsing is faster, deterministic, and does not consume a Wise action.

A message costs one action when the AI work succeeds, even if it performs several scene operations. Failed messages are not charged. Ordinary viewer movement and stored coordination edits made through the inspector are separate from the Wise allowance.

Finish by reopening the original broad cohort and checking the inspector. The scene should be reset and the stored workflow fields unchanged.
