## Change presentation without changing coordination data

@action: Ask Wise to colour the current clashes by priority, then sort the clash list worst first.

Colour modes and list ordering help reveal the pattern in a cohort. They do not update a clash's stored priority or status.

Ask a question such as, What is driving clash number twenty-seven? Wise can generate or show the clash explanation. Review that explanation as AI-assisted context, not an engineering verdict.

The first generated explanation uses a Wise action. Re-reading a saved explanation is free; regenerating it uses another action.
