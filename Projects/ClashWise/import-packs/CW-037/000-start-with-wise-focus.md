## Let Wise surface the first review target

@visual: Show an expanded Wise Focus card on Riverside Cycle 01 with its evidence rail and exact review action.

Wise Focus is the ambient attention layer on the dashboard and clash-set page. You do not start a chat or ask a question. ClashWise reviews current set facts and surfaces one bounded place that deserves attention.

The card can point to missing matrix setup, new or modified clashes, overdue work, unreviewed clashes, missing responsibility, unmatched rules, analysis failures, or unresolved session outcomes. Counts and destinations come from deterministic ClashWise data. Wise only shapes the concise explanation and ordering.

Every action is read-only. It opens an exact clash cohort, the assigned matrix or setup action, analysis or insights, or relevant session details. Wise Focus never changes a clash.

@action: Open the primary action, show the Viewing Wise focus chip on the resulting cohort, then remove it.

The chip proves that the grid is showing the focus definition rather than an unexplained subset. Remove it to return to the ordinary set view.

A stale focus can remain visible while ClashWise refreshes it. A clear state means Wise checked the available evidence and found no immediate focus; it is not a certification that every engineering issue is resolved.

Wise Focus does not consume a user-visible Wise action. It runs as product guidance and remains useful even when the set has never been analysed, although matrix and analysis evidence can make it richer.
