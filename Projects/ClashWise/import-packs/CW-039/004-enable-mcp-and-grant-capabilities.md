## Turn on the organisation safeguard

@action: As the synthetic organisation Admin, open Organization, Connected AI, Manage, and show M C P access disabled.

M C P connections are off by default. Enable them only when the organisation intends to use compatible AI clients, then save the organisation setting.

Existing clients cannot call ClashWise tools while the safeguard is off.

## Grant the member's minimum capability set

@action: On the member card, grant View clashes and Edit clashes for the controlled demonstration, leaving unrelated capabilities off.

The current grid separates viewing clashes, sessions, and matrices from editing clashes and managing sessions, matrices, or notifications.

Grant read capabilities broadly only when the data scope is appropriate. Keep edit and manage capabilities with people responsible for those records. Save the grant changes before connecting.

A client can never do more than the member's current organisation grant, even if it requested more during approval.
