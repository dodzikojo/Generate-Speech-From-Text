## Audit the effective permission, not just consent

OAuth approval records what the client requested and the user approved. The organisation grant remains authoritative on every call. If an Admin removes Edit clashes after connection, a later edit must be denied even though the connection row still exists.

## Operate credentials by lifecycle

Name API keys and connections for their owner and purpose. Review Last used, connected time, capabilities, and activity periodically. Revoke anything abandoned, unrecognized, or broader than the current task.

API key revocation is immediate and the secret cannot be recovered. M C P revocation blocks future token renewal; the revoked row can remain for review until it is deliberately deleted. Turning off the organisation safeguard fails all customer M C P calls closed.

The activity ledger is the evidence that connects the person, client, tool, target, and outcome. A safe integration is not merely one that connects successfully. It is one whose access can be explained, verified, reduced, and revoked.
