## Preview the connected report

@visual: Show the prepared ClashWise Power BI report with the five report pages, then select a count-by-status visual and the latest refresh time.

ClashWise provides a self-distributed Power Query connector and editable Power BI projects. The connector signs in through ClashWise OAuth and loads read-only reporting data for the projects the account can access.

This current path does not require an API key or a reporting password. Legacy export endpoints and profile API keys remain a separate compatibility surface for custom integrations.

The goal is not to build a polished dashboard from scratch. It is to install the trusted connector, open the supplied report, authorize the minimum read-only access, and prove that refresh follows current ClashWise membership.
