@action: Open the model or table view and identify projects, clash sets, current clashes, history, tags, matrices, sessions, and shared-insight metadata.

The reporting feed includes permanent clash numbers and coordination fields such as status, priority, responsible contact, and due date. It also carries rule configuration and configured colours, along with quantitative session outcomes.

Sensitive or unsuitable content stays out: notes, comments, attachments, viewpoints, passwords, member identities, and Wise-generated prose are excluded.

This is a reporting model, not a backup of every product record and not an edit channel back into ClashWise.

## Read the supplied model before customizing it

The editable Power BI project already contains relationships, measures, and report pages. Start by identifying the project, clash set, clash, matrix, history, and session tables and how permanent clash numbers relate within a set.

Do not treat the permanent number as globally unique across every set. Keep the set context in relationships and report labels.

Configured priority and status colours arrive with the reporting data. Reuse them where possible so a red or amber category means the same thing in ClashWise, the matrix export, and the report.

Before adding business measures, duplicate the project or use source control appropriate to P B I P files. Preserve a clean downloaded baseline for troubleshooting.

## Diagnose refresh failures systematically

If ClashWise is absent from Get Data, check the effective Documents folder, connector filename, Windows Unblock state, Data Extensions security setting, and whether Power BI restarted.

If sign-in is denied, verify the ClashWise account is active and belongs to the organisation and projects expected by the report. If Desktop works but Service does not, check the Standard gateway, its custom connector folder, connector version, service account access, OAuth data source, and semantic-model binding.

After revocation, the next refresh should fail while data already imported remains. Delete or replace that imported data when the reporting file itself must no longer retain it.
