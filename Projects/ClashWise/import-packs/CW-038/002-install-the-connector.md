## Download the official connector

@action: Open the public Power BI integration page and point to ClashWise dot mez plus the English report downloads.

Close Power BI Desktop before installation. Download ClashWise dot mez only from the official ClashWise integration page.

If Windows shows Unblock in the file Properties dialog, select it. Then place the file in the Custom Connectors folder under the Documents folder Windows opens for this account. Documents may be redirected through OneDrive, so do not assume a fixed disk path.

@screen: Show the destination ending in Microsoft Power BI Desktop, Custom Connectors, with user-identifying path segments cropped.

In Power BI Desktop, open Options, Security, and allow uncertified data extensions. The connector is self-distributed and not yet built into or certified by Microsoft. Restart Power BI Desktop after changing the setting.

Use Get Data to confirm ClashWise is available before opening the report.
