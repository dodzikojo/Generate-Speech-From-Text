## Choose portfolio or clash-set reporting

@action: Return to the integration page and show the Portfolio and Clash sets report packages.

The current page offers separate English downloads for portfolio and clash-set reporting. Choose the package that matches the audience rather than duplicating every page into one file.

Extract the prepared English package and open ClashWise Analytics dot P B I P in Power BI Desktop. The project is editable: it contains the report pages, semantic model, relationships, measures, and ten paged reporting tables.

The setup surface and supplied package are currently English-only. The data still represents project values as stored; this limitation concerns the delivered reporting experience.
