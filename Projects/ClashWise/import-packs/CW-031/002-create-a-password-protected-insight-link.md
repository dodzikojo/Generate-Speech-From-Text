## Choose expiry and password

@action: Select Share insights, choose the training expiry, enable Require a password, and create the link.

ClashWise generates the current short password automatically. Choose an expiry appropriate to the review rather than defaulting every stakeholder to the maximum lifetime.

The current dashboard dialog creates a link to this set's saved insights layout. The wider Shared Insights console can also compose and manage links.

## Handle the credential off-screen

@screen: Show Copy link and Copy password info without displaying the actual password or token.

Store the password outside the recording and send it separately when appropriate. Never paste the raw URL or password into captions, run sheets, screenshots, or production filenames.

The link is public access for anyone holding the credential. Password protection reduces accidental access; it is not user identity.
