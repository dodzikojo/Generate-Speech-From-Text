## Select the clash tests

@action: Open General, Group Clashes, tick the prepared test, and collapse or reopen the test pane once.

The left pane controls which native tests will be changed. Tick only the twenty-clash training test and verify the selected count.

If Group Clashes opened from the publish warning, the relevant tests may already be selected. Still read them back before applying.

## Add the first grouping rule

@action: Add a rule for Clash location, Level, then preview.

Rules build the composite group name from top to bottom. Start with Clash location and Level because it does not depend on one consultant's property schema.

For element-property rules, choose a category, property, and side. Side A uses the first element, B the second, Pair combines both values, and Either uses an available value from either side according to the tool's matching behaviour.

Preview after the first rule. This creates a baseline for understanding what the second rule adds.
