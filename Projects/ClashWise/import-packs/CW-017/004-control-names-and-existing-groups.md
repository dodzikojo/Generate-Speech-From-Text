## Decide what happens to existing groups

@screen: Show one prepared existing group and the Ungroup existing first option with its confirmation warning.

Leaving Ungroup existing first off preserves existing groups and groups eligible ungrouped results according to the current workflow. Turning it on removes the selected tests' existing grouping before creating the new structure.

Use replacement only when you intend to rebuild the grouping standard. Removing a group changes organisation, not the child clash's status, comments, or viewpoint, but it can disrupt a team that refers to the old group names.

The preview and confirmation are the final chance to catch that scope.

## Design a hierarchy people can navigate

Start with the question the group should answer. A top level by building or level helps a meeting move through space. A second level by discipline pairing or system helps route responsibility. A final band or property can separate size, zone, or another stable delivery unit.

Avoid hierarchies that reproduce a long raw property path nobody uses in coordination. Deep nesting hides small buckets and makes names too long for the Clash Detective tree.

Use the preview to inspect the largest bucket, the smallest buckets, ungrouped clashes, and duplicate-looking names. Adjust the rule before creating native groups.

## Understand workflow roll-up

Group status can reflect its child clashes according to Navisworks behavior. A group is a navigation container, not a replacement for reviewing the member clashes. Changing the grouping does not rewrite child comments, viewpoints, or cloud coordination history.

After apply, expand two groups and compare their member counts with the preview. Select one child and verify its status and viewpoint survived. Save the configuration as a reusable preset only after the generated structure matches the project standard.

When the model changes, rerun the preset against the updated test and review the preview again. A saved grouping recipe is repeatable, not automatically correct for every new result.
