## Generate the session report

@action: Choose Report PDF, wait for preparation, and open the downloaded training file.

Choose Report PDF. ClashWise prepares the document and downloads it through the browser.

Open the file and check the session title, date, attendee annotations, reviewed clashes, activity, notes, attachments, and generated minutes. Find number twelve and verify that the same decision and action appear.

The PDF is the circulatable record. It should be understandable to someone who was not in the live room, while still reflecting only recorded facts.

## Recognise what is absent

@screen: Compare the PDF with an untouched clash default and a piece of deliberately unrecorded rehearsal discussion.

An unchanged default does not appear as a meeting decision. Unrecorded speech does not appear. A clash edited after End is not inserted into this session.

That absence is a feature: the report does not pretend to know what the team meant. If a required outcome is missing, add it as a decision or action item and regenerate, rather than manually asserting that the automatic record captured something it did not.
