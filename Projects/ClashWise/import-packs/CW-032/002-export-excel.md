## Choose fields and coordination source

@action: Open More, Export, choose Excel, Matching current filter, and the Riverside-W38-MEP file prefix.

The column picker covers core clash fields, Element A and B, and custom published properties. Selections are remembered per set, so use Reset if an old export configuration is misleading.

Choose whether Status and Priority come from currently applied clash values or the matrix recommendations. Include audit fields, analysis summary, viewpoint URL, or full history only when the recipient needs them.

## Inspect the workbook

@action: Generate, download, and open the synthetic workbook.

Verify twelve data rows, clash numbers, intended coordination fields, and configured colours. A full-history Excel export can add an extra sheet; other delivery variants may package history separately.

The workbook is a point-in-time data export. It does not update with the set.
