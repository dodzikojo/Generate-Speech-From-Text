## Use the fixed BCF structure

@action: Choose BCF, Matching current filter, and generate Riverside-W38-MEP.

ClashWise writes a BCF two point one archive. Each in-scope clash becomes a topic with markup, comments, snapshot when available, and a three-dimensional viewpoint.

Column selection does not apply because BCF is a standard package, not a custom table.

## Test interoperability without overpromising

@screen: Import the synthetic package into the prepared compatible viewer and open one topic.

Verify the topic title and clash number, comments, snapshot, and camera. Receiving tools vary in how they map status, priority, authors, component identifiers, and labels.

BCF export is one-way in ClashWise. It does not import a BCF as a clash set, and it does not include the full source models.
