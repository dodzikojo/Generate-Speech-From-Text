## Preview a local result

@visual: Show a successful test title in AI Models with the active model badge, then show the same model named in Title Update settings.

Local AI gives Title Update a model that runs on this Windows computer. The element information used to generate a title is processed by that local model rather than sent to the ClashWise naming service.

This applies to clash-title generation. Wise chat and web clash analysis are separate cloud features.

Local also does not mean the plugin becomes completely disconnected forever. Download, first sign-in, subscription checks, updates, and later account or audit synchronisation can still use the network. The privacy boundary is the title-generation inference itself unless you enable cloud fallback.

## Check the workstation before downloading

@screen: Open the AI Models catalogue and point to the displayed size, languages, speed, accuracy, and hardware guidance.

Every model row shows the information you should use to choose: download size, status, supported languages, and relative speed and accuracy. Larger models need more memory and storage and usually take longer to respond.

Start with the current Recommended model rather than the largest catalogue entry. At recording time, verify the displayed model name and size on the shipped catalogue. Treat those values as live product data, not permanent narration.

Make sure free disk space comfortably exceeds the download size and leaves room for normal model and application work.
