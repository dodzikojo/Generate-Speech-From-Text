## Choose the installer that matches your work

@screen: Show the download page with the Full Suite and Starter choices, then highlight the Navisworks-year selector.

The download page offers two installer families.

Full Suite is the normal choice for this training path. It includes Title Update, Local AI, Property Mapping, Group Clashes, Sets and Clashes, Wise, and the Publish, Update, and Sync workflow.

Starter is the smaller clash-naming edition. It is useful when you only need the core naming tools, but it does not contain the complete coordination workflow used in the next lessons.

Choose the package for your installed Navisworks year, or use the combined installer when this computer has more than one supported Navisworks version. A plan controls which features you can use; the installer controls which plugin components are physically present. If you are unsure and intend to publish clash sets, choose Full Suite.

## Install with Navisworks closed

@action: Close Navisworks, run the prepared Full Suite installer, select the installed Navisworks year, and complete setup.

Close every Navisworks window before running the installer. If an older ClashWise version is installed, remove it first from Windows Installed apps. Uninstalling the plugin does not remove your Navisworks files, titles already written into them, or clash sets already published to the web.

Run the installer, confirm the Full Suite edition and the correct Navisworks year, and finish the installation. The standard installer installs for the current Windows user, so administrator permission is not normally required.

Now reopen Navisworks Manage. In the ribbon, look for the ClashWiseAI tab. If the tab is missing, first check that the installer year matches Navisworks, then close Navisworks and run the installer again. The full recovery checklist is linked below this video.

In Full Suite, the ribbon should include the General, Clash Management, Visibility, Login and Logout, and Support areas. Dashboard is also available as a route to the web app. The Starter ribbon is intentionally smaller, so a missing Publish button may mean the clash-naming edition was installed rather than a failed load.

ClashWise checks its version when it starts. A required update blocks continued use and opens the download route; an optional update can be dismissed until a convenient time. Updating uses the same basic process: close Navisworks and run the new installer for the correct year.

The installer adds commands to Navisworks, but it does not alter your model. Opening a document, signing in, or viewing the ribbon does not publish anything. Publish remains an explicit action that you will control in CW-005.
