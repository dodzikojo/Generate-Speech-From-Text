## Sign in inside Navisworks

@action: Open the ClashWiseAI tab, choose Login, and sign in with the same training account used on the web.

On the ClashWiseAI ribbon, open the Login and Logout panel and choose Login. Enter the same email and password you used on the website.

The plugin has no separate sign-up flow. Forgot Password opens the web recovery page, and every feature prompts you to sign in if the plugin does not have an active session.

After login, open Dashboard from the ribbon. This proves that the plugin can reach ClashWise and takes you to the web workspace for the current account.

If your company installed ClashWise through the Autodesk App Store, the plugin may be able to recognise the Autodesk account already signed in to Navisworks. The result is the same: verify the ClashWise identity and organisation before doing project work. The website itself still uses the ClashWise sign-in flow shown earlier.

If you belong to more than one organisation, use the organisation switcher at the top of the web navigation drawer. For this series, select Northstar Coordination Training. Always check this context before publishing: a clash set is created inside the active account and organisation, so being in the wrong workspace causes avoidable confusion later.

## Confirm silent sign-in

@visual: Close and reopen Navisworks, then return to the ClashWiseAI ribbon without showing a login dialog or any stored credentials.

ClashWise stores the plugin credentials in encrypted form on this computer. Close Navisworks, reopen it, and select a harmless command such as Dashboard. Returning users should be signed in silently, without typing their password again.

Never expose stored credentials, browser autofill, personal notifications, or a real customer account while recording this check. A clean training profile keeps the result easy to see.

You now have the same identity available in both workspaces: Navisworks for preparing and publishing clash results, and the web app for shared coordination.

If a command still says Please log in, check internet access and sign in once while online. Some plugin features can continue during a limited offline grace period after that verification, but publishing, web coordination, account checks, and updates require a connection. Keep the exact grace-period and subscription messages in the installation article because they may change independently of this lesson.

Finally, sign out only when this is a shared Windows profile or you deliberately want to switch accounts. The Login button is a split control: its second action is Logout. On your own secured workstation, silent sign-in is the expected day-to-day behaviour.
