## Know what is live and what is generated

@screen: Contrast current metric and chart updates with the AI summary generation time.

The dashboard data refreshes as clash values and analyses change. The AI summary is a generated interpretation stamped with its own time and may need regeneration.

A public insights link shows live dashboard data through the saved layout; a PDF export remains a point-in-time snapshot.

## Build the presentation around decisions

Start with the questions the audience must answer: Is risk falling? Which systems carry the unresolved workload? Where is responsibility concentrated? Are due dates moving in the right direction?

Choose tiles that answer those questions. A count without comparison or context may look impressive while saying little about coordination progress.

Arrange the first screen for the meeting room. Put the headline state and change over time near the top, then responsibility and location breakdowns, then supporting detail. Test the layout at the screen size used for the actual presentation.

## Know what saving means

@action: Move one prepared tile, save the layout, reload Insights, and confirm the position persists.

The current set keeps one shared saved layout. It is not a collection of named personal dashboards. A layout change can therefore affect the next person who opens the set.

Use a protected insight link for a live external presentation of that saved layout. Use a PDF when the recipient needs a fixed record. Before sharing either, open a chart and trace its cohort back to the underlying permanent clash numbers so the story remains auditable.

Regenerate an AI summary when the data has materially changed, and review the generated interpretation before presenting it as context.
