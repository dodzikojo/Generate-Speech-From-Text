## Preview the decision-ready dashboard

@visual: Show the curated Riverside Insights layout with totals, resolution, priority, status, owner workload, aging, trends, and reviewed AI summary.

Insights is the step back from individual clashes. A useful layout answers a small set of questions: how much work remains, what is urgent, who owns it, what is overdue, whether rule coverage is healthy, and whether the trend is improving.

The dashboard requires a completed analysis and opens from the selected clash set's Insights action.

## Read the headline honestly

@screen: Show resolution percentage, clash count, health label, live state, and updated timestamp.

The health label summarises the current resolution rate. It is a product indicator, not an independent engineering judgement.

Refresh after a significant update or rerun analysis when the set changed. Insights combines the latest completed analysis with current web-side edits.
