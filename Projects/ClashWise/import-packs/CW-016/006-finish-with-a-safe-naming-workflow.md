## Know what persists

@visual: Show the restored native test, the saved Riverside naming configuration, and the local recovery/audit boundary.

The Navisworks file keeps applied titles when you save it. Naming settings persist for the Windows user. Recovery proposals and original-title audit data are local records used to protect the workflow across sessions.

Changing computers or deleting local records can affect later restore availability, so archive important model states according to the project standard rather than treating restore as the only backup.
