@action: Select a prepared clash test in Navisworks and open the Publish workflow.

The cycle begins after you have run your clash tests in Navisworks.

Choose Publish, select the tests you want to coordinate, give the set a useful name, and send the results to ClashWise. The plugin can include viewpoint images, three-dimensional captures, model context, locations, and element properties alongside the clash data.

When processing finishes, the set appears under Clash sets on the web. Every clash receives a permanent number within that set. Lead with that number in meetings, links, comments, and reports, because the number stays stable even when a title changes or the set is updated.
