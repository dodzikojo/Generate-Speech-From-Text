@screen: A prepared Clash Matrix followed by the matrix selector and Run analysis action on the clash set.

A published set starts as clash information from Navisworks. To turn it into a coordinated worklist, create and assign a Clash Matrix.

The matrix is your project rulebook. Each element-class pairing can carry the priority, status, responsible contact, tolerance, and tags your team wants to use. ClashWise does not impose a fixed engineering taxonomy. Your matrix defines what the recommendations mean for this project.

When you run analysis, ClashWise matches each clash to the most appropriate matrix rule and adds a recommended priority, status, and responsible contact. The matched rule remains visible, so you can see where the recommendation came from.

These recommendations accelerate review; they do not replace coordination judgement. The team can accept them, change them, or record an intentional exception.
