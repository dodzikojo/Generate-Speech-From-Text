Expose VoiceBench commands through the official MCP C# SDK 2.3.0 using stdio and a same-user named pipe. Discovery is static; the first operational call attaches to or launches the installed desktop. The pipe enforces Windows SID/elevation, rejects remote clients, bounds payloads and propagates cancellation.

Slice 2 of 4, stacked on `codex/local-mcp-application`. Adds typed tools, seven resources, subscriptions, paged text, audio previews and artifact links.

Validation: 25 official-SDK/bridge integration tests cover discovery without launch, Unicode, schema errors, subscriptions, cancellation, concurrency and clean stdout. Actual cross-account/elevated-token attempts were not run.
